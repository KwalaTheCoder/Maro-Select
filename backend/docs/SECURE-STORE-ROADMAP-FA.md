# آماده‌سازی نسخه امن فروشگاه مارو سلکت

## وضعیت
این برنچ برای بررسی و تست است؛ روی main مرج نشده و روی GitHub Pages پنل واقعی فعال نیست.

- در دموی عمومی، مسیر `#/admin` پیام غیرفعال بودن مدیریت نمایش می‌دهد. این یک کنترل نمایشی است؛ امنیت واقعی فقط از سمت Laravel تأمین می‌شود.
- مسیرهای `/api/admin/*` در Laravel از قبل به middleware مدیر محدود هستند و ورود رمز عبور/نشست/CSRF و TOTP اختیاری دارند.
- فیلدهای نام و نام خانوادگی در فرم جدا شده‌اند ولی در پایگاه داده فعلاً به شکل یک نام کامل ذخیره می‌شوند.
- استان و شهر از فهرست کشویی مرتب انتخاب می‌شوند و سرور جفت انتخابی را بررسی می‌کند. فهرست کنونی شامل ۳۱ استان و ۱۴۷۸ نام شهر یکتا (۱۴۸۱ رکورد شهر در داده منبع ۱۴۰۴) است؛ روستاها در این فهرست نیستند؛ پیش از فروش واقعی باید پیش از استفاده واقعی با فهرست سرویس‌دهی پستی و تغییرات جدید تطبیق داده شود.
- وضعیت فروش هر تنوع محصول مستقل از عدد موجودی با `sale_enabled` کنترل می‌شود. برای اجرای نسخه جدید migration الزامی است.

## نصب و آزمون
1. PHP 8.2+، افزونه‌های لازم، Composer، دیتابیس MySQL/MariaDB و HTTPS فراهم کنید.
2. مسیر public وب‌سرور باید **فقط** `backend/public` باشد؛ پوشه `backend` یا ریشه مخزن را عمومی نکنید.
3. در `backend`: `composer install --no-dev --optimize-autoloader` و کپی `.env.example` به `.env`؛ کلید را با `php artisan key:generate` تولید کنید.
4. متغیرهای پایگاه داده، `APP_URL`، `APP_ENV=production`، `APP_DEBUG=false`، `SESSION_SECURE_COOKIE=true`، `MARO_LIVE=false`، `PAYMENT_DRIVER=disabled` را بررسی کنید.
5. `php artisan migrate --force`، ساخت مدیر با روش مستند نصب و فعال‌سازی TOTP، و `php artisan test` را اجرا کنید.
6. از نسخه پشتیبان پایگاه داده و فایل‌های خصوصی، بازیابی آزمایشی و مانیتورینگ خطاها مطمئن شوید.
7. پیش از فعال‌سازی درگاه، تست مستقل پرداخت، جلوگیری از تکرار سفارش، رزرو موجودی، مجوزها، لاگ‌ها و امنیت آپلود لازم است.

## معیار انتخاب هاست
- پشتیبانی از PHP 8.2 یا بالاتر و افزونه‌های Laravel، Composer/SSH و cron
- دیتابیس پایدار، بکاپ قابل بازیابی، SSL، امکان تنظیم document root به `public`
- دسترسی به لاگ، امکان اجرای migration و وظایف زمان‌بندی‌شده
- انتخاب مرکز داده نزدیک مشتریان و سازگاری درگاه پرداخت با محل سرور

**این برنچ گواهی امنیت یا تأیید آماده‌بودن برای فروش واقعی نیست.** تا زمان اجرای تست‌های عملیاتی و بازبینی مستقل، داده واقعی مشتری دریافت نشود.
