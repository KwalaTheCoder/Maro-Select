# MARO SELECT — نسخهٔ اولیهٔ قابل نصب

فروشگاه فارسی با Laravel 12، Blade، JavaScript سبک، CSS محلی و پایگاه دادهٔ قابل مهاجرت به MySQL/MariaDB. مسیر خرید به Node، Redis، CDN، API هوش مصنوعی یا ورود خارجی وابسته نیست.

**وضعیت تحویل:** پیاده‌سازی اولیه و تست محلی؛ آمادهٔ نصب آزمایشی. مجوز اعلام آمادگی برای فروش واقعی نیست. درگاه پیش‌فرض غیرفعال است. پذیرش نهایی پس از تست روی MySQL هاست، درگاه مالک و تکمیل اطلاعات واقعی انجام می‌شود.

## شروع

- راهنمای نصب و دامنه: `docs/INSTALL-FA.md`
- راهنمای تصویری مدیر: `docs/OWNER-GUIDE.html` (در مرورگر باز کنید)
- گزارش آزمون: `docs/TEST-REPORT-FA.md` و خروجی واقعی `docs/TEST-OUTPUT.txt`
- معماری و محدودیت‌ها: `docs/ARCHITECTURE-FA.md`
- تنظیمات نمونه: `.env.example`؛ فاقد کلید و رمز
- مهاجرت نسخه‌بندی‌شده: `database/migrations/`

فایل `vendor/` داخل بستهٔ نصب قرار دارد. npm و Composer برای اجرای سایت روی هاست لازم نیستند. برای توسعه و تغییر نسخهٔ وابستگی‌ها، Composer در محیط آماده‌سازی استفاده می‌شود. هیچ حساب مدیر، رمز ثابت، کلید پذیرنده یا دیتابیس مشتری در بسته قرار ندارد.

## فرمان‌های نصب روی هاست

```sh
cp .env.example .env
# مالک/نصاب مقادیر واقعی .env را در کنترل‌پنل امن هاست وارد می‌کند.
php artisan key:generate
php artisan migrate --force
php artisan maro:admin
php artisan config:cache
php artisan view:cache
```

ریشهٔ وب فقط `public/` باشد. پوشهٔ پروژه، `.env`، `storage/` و بکاپ‌ها نباید زیر مسیر عمومی قرار بگیرند. هرگز خود پروژه را یکجا داخل public_html قابل‌دسترسی قرار ندهید.

## تست توسعه

```sh
php vendor/bin/phpunit --testdox
```

وابستگی‌های تست در بستهٔ تحویلی موجودند. روی هاست عمومی مسیرهای تست و docs را خارج از public نگه دارید. برای ایجاد دادهٔ نمونه فقط در محیط local:

```sh
php artisan db:seed --class=DemoSeeder
```

این seed مدیر ایجاد نمی‌کند؛ دادهٔ نمونه در حالت فروش واقعی قابل خرید نیست.
