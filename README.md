# MARO SELECT — مارو سلکت

دموی فارسی فروشگاه جوراب. تصاویر و فونت‌ها محلی هستند.

نسخهٔ GitHub Pages نمایشی است. اطلاعات کالا نمونه است و پرداخت واقعی فعال نیست. پنل نمایشی اطلاعات را در مرورگر همان دستگاه نگه می‌دارد.

کد Laravel در پوشهٔ backend برای نصب روی هاست PHP/MySQL قرار دارد. راهنمای نصب در backend/docs/INSTALL-FA.md است. فایل .env، دیتابیس و داده‌های مشتری منتشر نشده‌اند.
